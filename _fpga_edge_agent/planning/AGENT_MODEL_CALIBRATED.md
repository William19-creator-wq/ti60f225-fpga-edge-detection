## 1. State machine

### 1.1 需求状态（每项需求一条，绑定版本）

`未做 → 代码有 → 编译通过@run → 实物通过@版本 → 已录影@版本`

- `编译通过`：指定 run 的综合、布局布线、最终时序都通过，且 bit 已登记 SHA256。
- `实物通过`：只能来自用户的实际观察（D4），记录观察内容和日期。
- `已录影`：记录影片文件位置。
- 不跳级。新版本不继承旧版本的 `实物通过` 和 `已录影`：基准换版本（D2）后，新版本从 `编译通过` 重新开始，旧记录保留。

### 1.2 编译状态（每个 run）

`准备 → 编译中 → 通过（有 bit）| 失败：综合 / 容量 / 布线 / 时序`

- 同一目标连续失败计数，到 2 次进入"暂停，等用户决定"（D3）。
- 改动预计超过 60,531 XLR，编译前就进入 D3。

### 1.3 硬件闸门（每个待测版本）

`等待下载 → 等待观察 → 分析中 → 通过 | 问题清单`

前两步只能由用户推进（D5）。名称沿用现有 STATE_MACHINE.md 的 `WAITING_HUMAN_PROGRAM`、`WAITING_HUMAN_OBSERVATION`、`ANALYZING`。

### 1.4 交付基准

当前基准为 031。候选版本要同时满足"编译通过、实物表现不差于基准、用户批准（D2）"，才能成为新基准。

### 1.5 源码所有权（每个可写工作目录）

`无主 | Codex | Claude Code`，同一时间只有一个；切换由用户决定（D8）。

### 1.6 状态存放

只用一个状态文件（建议 `state/DELIVERY_STATUS.md`）作为进度依据。现有 `integration-status.json`、`full-goal-completion-audit.json` 保留为历史；`PROJECT_STATE.json`、`TASK_LEDGER.csv` 不改，但不再作为本次交付的进度依据。

### 1.7 与现有 STATE_MACHINE.md 的差别

| 保留 | 本次不用 | 新增 |
|---|---|---|
| 硬件闸门段（1.3） | H0 → … → R0 逐节点推进（现在是一颗整合 bit）；与状态机脱钩的设计标签 | 需求五级状态、编译失败状态与计数、交付基准、源码所有权 |

## 2. Workflow

| 流程 | 何时用 | 步骤 |
|---|---|---|
| W0 会话开始/结束 | 每次会话 | 开始：读目标与约束 → 决策点 → 状态文件；检查源码所有权和正在运行的编译；有新的用户反馈先处理。结束：更新状态文件；新决定追加到决策点清单 §4 |
| W1 上板测试 | 有待测 bit | 提供 bit 与操作说明 →【用户】下载 →【用户】反馈现象 → 对照预期定位到链路段（S3）→ 问题清单 → 需改代码则进 W2 → 更新需求状态（`实物通过` 需用户确认） |
| W2 修改—编译 | 需改 RTL 或约束 | 确认在范围内（D1）且有所有权（D8）→ 从交付基准复制新的工作副本 → 写短变更卡（改什么、为什么、影响哪些模块的入参/出参）→ 修改 → 整机编译（S1）→ 判读资源与时序（S2）→ 通过：登记 bit，进 W1；失败：计数，到 2 次触发 D3 |
| W3 交付 | 第二周 | 冻结交付版本 → 设计说明（S4）→ 录影清单（每项需求一个镜头）→【用户】录影 → 打包核对（S5）→【用户】定稿（D6） |

W2 的分支来源：031 目录本身只读，修改都在新的副本中进行。开发目录 `track4_board_first_20261011` 含已排除的 A6 大改（约 70k XLR），不作为交付分支来源；其中个别修正（如 POINT 末包补零）如确有需要，用短变更卡移植。

与现有 WORKFLOW.md 的差别：
- 逐节点上板 → W1 测试一颗整合 bit；
- 每次改动一份 v0.2 设计书 → 短变更卡，加上一份交付设计说明（保留"可理解"的目标，改变形式）；
- 新增 W3：现有流程没有录影、打包和讲解文件；
- 记录方式改为本地文件（PostgreSQL 见 §5）。

## 3. Plan

Plan 是一次任务的步骤清单，不是设计书。每份不超过一页，包含：
- 目标：推动哪项需求的哪个状态转换（§1）；
- 流程：W1 / W2 / W3；
- 步骤：每步对应一个 Skill；
- 停止条件：可能触发的决策点；
- 完成判据。

存放：`planning/CURRENT_PLAN.md` 只放当前有效计划。旧的 `design-*.md` 为历史，本期间不再新增，W2 的短变更卡除外。

| P3 首测问题修正 | W2 | M1 | 视 P1 结果触发，可能没有 |
