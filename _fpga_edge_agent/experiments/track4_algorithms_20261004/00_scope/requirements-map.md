# 十一项要求与算法优先次序

本页是范围/追踪；R1 本批软件结果见[实际交付](../05_delivery/r1-software-acceptance-v1.1.md)。生产1920×1080保留，小图仅调试；最新用户明确允许板卡现有DDR3，仍禁止新增外接存储。完整来源见[官方映射](../../../docs/requirements/TRACK4_REQUIREMENTS.md)，最新[五类工作整合v0.8](../../../planning/design-TRACK4-ALGORITHM-INTEGRATION-001.md)优先于历史无DDR路线的边界描述。

| 原要求 | 本次算法可先做的部分 | 当前/后续位置 |
|---|---|---|
| T4-B1 采集/缓存 | 规范像素身份、行窗口、可暂停模拟输入 | R1行窗口；实体CSI/相机接入后续，未完成 |
| T4-B2 灰度 | 固定点77/150/29、舍入与位宽 | R1算法核软件PASS，含1080p/综合/PNR/STA/bit；生产输入输出及硬件验收仍待 |
| T4-B3 Sobel | 两行窗口、梯度L1、严格阈值 | R1算法核软件PASS，含1080p/综合/PNR/STA/bit；生产输入输出及硬件验收仍待 |
| T4-B4 HDMI/对比 | 分屏/覆盖像素逻辑和同源坐标 | R2算术；真实HDMI时序/serializer后续，未完成 |
| T4-B5 源码/约束/视频 | 按范围真实源码、工程/约束、中文操作/日志/bit | R1独立软件包已交付；完整十一项代码/生产约束及视频仍未完成，实体视频依用户暂不做 |
| T4-A1 中值 | 九值并行比较网络、独立复制边界 | R1算法核软件PASS，含1080p/综合/PNR/STA/bit；生产输入输出及硬件验收仍待 |
| T4-A2 按键阈值 | 消抖、饱和、job原子快照 | R1只快照；R2按键/控制，未完成 |
| T4-A3 DDR帧缓存 | 按用户最新明确回复恢复板载DDR3容量/服务/校准/布局设计 | ACTIVE_DESIGN_DEPENDENCY，未实现/验证；旧暂缓保留历史，正式任务账本未改 |
| T4-A4 完整Canny | Gaussian/梯度/方向/NMS/双阈值及精确闭包 | R2流段→R4闭包，未完成 |
| T4-A5 彩色叠加 | 原RGB/edge同身份交接、覆盖优先级 | R2；R1 FO仅M/edge，不能冒称已对齐彩色 |
| T4-A6 圆/旋转矩形 | 独立数值核、候选/拟合/核验/去重/标注及质量集 | R3→R4，未完成 |

95%每类P/R和IoU≥0.5一对一评价保持；旧尺寸/最多目标/噪声/遮挡建议只作为比较轴，不能重新变成硬验收界限。处理fps、相机fps、显示Hz分别记录。

R1通过只覆盖其声明算法与25MHz独立工程；不将bit存在解释成十一项或硬件通过。正式H0/任务账本均未更新。
