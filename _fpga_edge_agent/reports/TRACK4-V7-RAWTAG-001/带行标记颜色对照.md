# 带行奇偶标记的颜色采样比较

以下R/G/B为依据红蓝响应推断的BGGR映射，不是直接从信号名得来的颜色。有效RAW行：偶数低B高G；奇数低G高R。结合既有仿真映射对应P11。

|采样|R均值|G均值|B均值|
|---|---:|---:|---:|
|red_tag_01|34.734|24.262|17.930|
|blue_tag_01|49.246|73.415|52.486|
|blue_tag_02|51.498|88.372|63.039|
|white_tag_01|101.441|121.787|62.516|
|white_tag_02|253.518|254.982|157.260|

white01未饱和；白纸在单位增益时G高、B低，P11此前偏绿与此相容。white02多通道削顶，必须排除出白平衡拟合；不能把两次白纸亮度差直接归因于某个自动曝光行为。
P00人工GBRG色卡正常，但真实RAW的有效排列支持BGGR，颜色相位与白平衡是两个独立问题。
白纸01简单均值比G/R约1.20、G/B约1.95仅供诊断，尚未扣除黑电平，不能当作完成标定参数。红蓝白的响应差别不能用于判断帧率或完整噪声性能。
用户红色采后明确确认实时；蓝白回复为“可以了/也可以了”，仍需最终确认全过程实时，没有强行记为已确认。
