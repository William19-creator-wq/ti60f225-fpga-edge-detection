usage: efx_run.py [-h] [--prj] [-f FLOW] [--family FAMILY] [-d DEVICE]
                  [--timing_model TIMING_MODEL] [-t TCL_SCRIPT]
                  [-v EXTRA_FILES [EXTRA_FILES ...] | --flist FLIST]
                  [--tb TB_EXTRA_FILES] [--tb_top TB_TOP] [--dir SOURCE_DIR]
                  [--map_opts MAP_OPTS [MAP_OPTS ...]]
                  [--pt_opts PT_OPTS [PT_OPTS ...]]
                  [--pnr_opts VPR_OPTS [VPR_OPTS ...]]
                  [--pgm_opts PGM_OPTS [PGM_OPTS ...]] [-m]
                  [--sim_opts SIM_OPTS [SIM_OPTS ...]] [--aldec] [--ncsim]
                  [--output_dir OUTPUT_DIR] [--work_dir WORK_DIR]
                  [--timeout TIMEOUT] [--un_flow [UN_FLOW]]
                  [--physical_syn_input PHYSICAL_SYN_INPUT] [--res_compare]
                  design

Efinity command line runner

positional arguments:
  design                design name

options:
  -h, --help            show this help message and exit
  --prj                 utilize XML project file
  -f FLOW, --flow FLOW  efx tools flow. Options include: map, interface, pnr,
                        pgm, compile, program, rtlsim, mapsim, pnrsim, full,
                        ptsimrtl, ptsimfc, sta_tclsh, setup_efxlib
  --family FAMILY       family
  -d DEVICE, --device DEVICE
                        device
  --timing_model TIMING_MODEL
                        timing model
  -t TCL_SCRIPT, --tcl_script TCL_SCRIPT
                        Optional Tcl script to be used with the 'sta_tclsh'
                        flow. A Tcl interactive shell will be started if
                        ommitted.
  -v EXTRA_FILES [EXTRA_FILES ...]
                        additional HDL files to map
  --flist FLIST         path to text file listing additional HDL source files
  --tb TB_EXTRA_FILES   testbench HDL files (simulation only)
  --tb_top TB_TOP       top-level testbench module name (simulation only)
  --dir SOURCE_DIR      path to search for source files
  --map_opts MAP_OPTS [MAP_OPTS ...]
                        pass option string to efx_map directly
  --pt_opts PT_OPTS [PT_OPTS ...]
                        pass option string to interface designer directly
  --pnr_opts VPR_OPTS [VPR_OPTS ...]
                        pass option string to efx_pnr directly
  --pgm_opts PGM_OPTS [PGM_OPTS ...]
                        pass option string to efx_pgm directly
  -m, --modelsim        use Modelsim or Questasim simulator
  --sim_opts SIM_OPTS [SIM_OPTS ...]
                        pass option string to simulation tools directly
  --aldec               use Aldec Active-HDL or Riviera-PRO simulator
  --ncsim               use Cadence simulator
  --output_dir OUTPUT_DIR
                        output directory
  --work_dir WORK_DIR   work directory
  --timeout TIMEOUT     cumulative timeout for all stages in seconds
  --un_flow [UN_FLOW]   Enable unified netlist flow (on/off)
  --physical_syn_input PHYSICAL_SYN_INPUT
                        path to physical synthesis request file
  --res_compare         compare map resource usage against reference
