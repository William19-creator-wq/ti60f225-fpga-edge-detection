# 第三方资料与代码来源

本项目工作副本包含用户提供的Ti60F225 V4与VF HDK参考、SC431HAI配置和数据手册、DDR控制器、原厂受保护IP、Efinity生成接口及比赛群参考材料；自研算法、适配和诊断代码与这些依赖一起保存在私有仓库中。

原厂版权注释、许可说明和保护块保留。项目没有把第三方IP或资料统一改成MIT/Apache等开源许可，也没有声明用户获得额外分发权。公开仓库或对外发布前需分别确认各来源的许可。

原始整套HDK与工具安装包留在本机只读。仓库中的工作副本是项目实际使用的文件，来源与SHA256见已有baseline、artifact manifest和Git导出清单。
