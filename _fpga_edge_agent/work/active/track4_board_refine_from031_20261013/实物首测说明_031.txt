3. Efinity 中选择 Open Project，打开本目录 track4_board.xml。
4. 打开 Efinity Programmer，选择本地下载器、outflow\track4_board.bit 和 JTAG 模式。
   点击 Program FPGA / Start Program。首次为 JTAG 易失配置；掉电后需要再次下载。
   本次使用 .bit，不进行 Program Flash 或 Flash 擦除。
   按钮名称依据本机 Efinity 2026.1 随附 Programmer 帮助；下载器须能枚举目标芯片。
5. 保存下载控制台的成功/失败信息。成功后短按并释放 KEY1，等待首帧。
6. 先观察默认画面，再按下一节依次检查按键反应。

三、正常情况下能看到什么

上电/复位默认模式为 4：彩色摄像头画面 + 红色边缘叠加。
将白纸上的黑色粗线、圆或矩形放到镜头前，轮廓位置应出现红色边缘。
画面实际更新速度由采集、DDR 和算法共同决定；1080p60 是 HDMI 扫描配置，不是已测处理帧率。

六种模式按 0→1→2→3→4→5→0 循环，短按 KEY3 在松开后切换：
0：彩色摄像头画面。
1：灰度画面。
2：左半幅灰度、右半幅 Sobel 二值边缘。
3：黑底白线的 Canny 边缘。
4：彩色画面叠加红色 Canny 边缘。
5：彩色/红色边缘上叠加初版几何候选框和 C/R 字母。

默认模式 4，所以首次短按 KEY3 进入 5，再短按进入 0。
模式 5 的候选只是四组可见强轮廓的包围盒与方向分布判断。
圆候选框为绿色，矩形候选框为黄色，C/R 字母为白色。
它尚未实现完整圆拟合、任意旋转矩形、遮挡、缺整条边、重叠识别或识别率指标。
这版不要按这些完整复杂识别要求验收。

中值滤波已作为算法前级接入；没有单独的“中值滤波画面”模式。
POINT 方向、LS/TLS/FIT、anchor 数值链路已连接，但完整数值结果没有直接显示在屏幕上。

四、按键

KEY1 / P13：复位，恢复默认模式和初始参数。
KEY0 / C4：增加边缘阈值；一般会减少弱边缘。
KEY2 / N13：降低边缘阈值；一般会增加边缘，也可能增加噪声。
KEY3 / A3：短按切换模式；长按约 0.22 秒切换冻结/恢复。
  为便于区分，短按尽量少于 0.2 秒，冻结操作按住约 0.5 秒再松开。
KEY0 + KEY2 同时按：切换 Bayer 相位，共四种。仅在颜色/棋盘伪色异常时逐次观察。
  默认相位为 1。相位和阈值作用于后续接纳的处理帧，画面不一定在按键沿立即改变。

冻结后，移动纸张时显示应维持已发布画面；再次长按后恢复后续帧更新。
冻结时若处理帧尚在途中，最后画面交接可能需要等待该帧关闭。

五、LED 与无画面时的定位

led[0] / N14：DDR cal_done 后输出周期翻转，预期可以看到闪烁。
led[1] / P14：正常未冻结时输出 0；冻结时周期翻转；board_fault 时固定输出 1。
LED 亮灭极性以实际电路为准。led[0] 闪烁仅表示校准指示，摄像头与 HDMI 要以实际画面判断。

若没有画面，优先记录：
  A. Programmer 是否下载成功、识别到的芯片型号。
  B. 显示器提示“无信号”，还是已经锁定 1080p60 但画面为黑。
  C. 两个 LED 是闪烁还是固定状态，复位后是否改变。
  D. 短按 KEY3 切到模式 0 后是否有彩色图，是否更新。
  E. 摄像头型号、板卡丝印、HDMI 使用的接口。
这些现象可以区分下载、时钟/校准、采集、帧发布和显示问题。
