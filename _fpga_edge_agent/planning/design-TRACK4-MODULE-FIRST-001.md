## B. 整体外部行为

以功能增量推进：必要可读设计→RTL/独立参考/TB→单模块正确性→邻接组合→整包正确性→性能及物理实现闭合。模块所在整体位置和相邻端口须先明确；整包工具结果无需先于模块代码出现。

正常例：高斯模块的系数/舍入/边界、输入输出格式、窗口供给和停顿保持已清楚，就做模块实现和独立单测；HDMI引脚与DDR校准未完成不阻塞这个纯计算模块。
阻塞例：同一个模块到底收原像素还是窗口中心像素、输出有效哪一拍仍不清楚，必须补该局部设计；不能等联调才首次决定。若需全帧随机访问，接口必须规定容量/读写语义，模块测试可在该合同上验证，物理适配的完成另列。

## C. 模块职责与推进次序

1. 保留R1实际代码、参考、123场景和物理/bit记录，按需复用，不为策略变化重跑已通过结果。
2. 优先已有[完整R2流段设计v1](design-TRACK4-ALGORITHM-R2-STREAM-IMPLEMENTATION-001.md)：高斯、新梯度/方向、NMS/分类，按局部接口生成和验证，再接短链。其现有48输入及批准状态保持；不重开无关整机分析。
3. 按键消抖/阈值更新、颜色对齐/叠加、标注等独立模块，复用现有局部设计；只补实际缺少的端口、步骤和测试，不等待全部识别/DDR物理资格。
4. 精确Canny滞后连接、圆/旋转矩形的候选/拟合/判定等，逐个明确实际存储合同、数值与结束条件，实现和单测后接完整链。继续保原算法和质量要求，不以减少角度/目标/尺寸换通过。
5. 相机、DDR、HDMI适配层按真实IP和板卡合同实现/验证。用短链尽早暴露接口/缓冲问题，与纯算法进展交错推进，不让一个适配层未知阻塞所有独立计算模块。
6. 全部接入统一顶层，再做资源/最坏服务与时序优化及最终bit。既有复杂目录/lease/日志候选保为参考；未直接支撑当前功能或必要交接的机制不继续扩张。

## D. 接口与组合设计的最小边界

写模块前须明确：端口方向/位宽/signed/单位/合法值，输入输出数量和坐标，时钟/复位，接受与交付事件，停顿保持，配置生效，必要RAM端口/读延迟/地址边界，以及直接相邻模块的保证。明确两条样例：普通路径和边界/停顿/复位路径。

模块前只做粗预算：需要多少行/帧/计数位，主要乘法器/存储的大致量级，是否有明显不可能的结构。精确全机LUT/FF/RAM/DSP、真实DDR带宽、最高时钟和最坏帧时间列为实现后的测量/整合验收，不能伪填达标，也不要求预先证明所有未来模块。

未完成的生产硬件适配保持明确边界。仿真模型的延迟、反压、错误与容量必须写清；模型通过只证明合同条件下的算法，不能取代真实DDR/CSI/HDMI验证或用stub遮住总工程缺件。

## E. 每模块的中文操作草图

每个模块只写能对应实际代码的必要内容：

1. 做什么，输入/输出是什么，parameter合法范围及位宽。
2. 分成哪些组合计算、时序寄存器、必要状态机、RAM或子模块；不为无状态算术硬加状态机。
3. 输入真正被接受时取哪些旧值/配置；先扩展位宽做何种计算，怎样舍入/比较/处理边界。
4. 哪些值用组合赋值，哪些在时钟沿用非阻塞赋值更新；输出对应哪份输入、何时有效。
5. 气泡/反压/复位/换帧/结束时哪些数据保持、推进或作废；RAM内容与valid状态分别处理。
6. 上游→本模块→下游交接的一个逐拍例子；独立参考和TB如何观察与判定。

草图足够读懂并覆盖模块当前正确性即可；不逐变量写论文、不先穷举整机风险、不不断增设与功能无关的管理结构。代码注释保留契约、理由和易错点，草图与实现同步。

## F. FPGA实现仍需考虑的条件与时点

| 条件 | 何时考虑到必要深度 |
|---|---|
| 可综合语法、位宽/溢出、组合完整性、无多驱动/意外锁存 | 写每个模块前明确，编码与初步综合立即检查 |
| RAM容量/端口/读延迟、FIFO满空、DSP用途 | 局部先粗设计；综合核实际推断；整合后完整预算 |
| 时钟/复位/CDC、配置与像素/帧身份 | 模块边界先明确；跨域适配单测和整合验证，物理阶段核约束 |
| 相机格式/初始化、DDR校准/读写错误、HDMI时序/IP参数 | 对应适配层设计/验证；独立纯算术模块不用先解全部硬件细节 |
| 引脚、电压/IO标准、PLL和SDC | 对应板级顶层冻结前必须落实；最终PNR/STA/bit前核实际工具报告 |
| 吞吐、延迟、仲裁、缓冲溢出与完整资源 | 前期粗排明显不可行；短链开始测量；整包后按真实瓶颈优化 |
| 复位中断/换帧/停顿/错误恢复 | 单元先覆盖自己责任，短链和整包补跨模块场景 |

性能不能完全到最后才第一次想，但无须在模块编码前证明全机最终达标。算法正确、可综合、实际存储语义与必要时间行为必须先保证；详细性能调优依据真实实现数据。

## G. 实施与验证计划

单元：独立数值参考、普通/边界/非法值、气泡/反压/复位/换帧/配置；编译、必要初步综合核RAM/DSP和锁存/多驱动，不为可逆文档变更新增测试。
短链：窗口→高斯→梯度→NMS等，核坐标/帧/valid对齐、数量和边界，覆盖不同时刻停顿/结束。
整包：完整Canny闭包、识别质量、原彩色对齐、阈值更新、DDR冻结/恢复与生产IO，核同帧结果和失败恢复。
性能/物理：实际资源/共享/端口冲突、服务与处理时间；综合/接口/PNR/STA后定位瓶颈，再采用流水/复用/缓存/布局等改进，不静默改变算法验收。必要检查通过才生成/登记bit，随后停止硬件操作。
