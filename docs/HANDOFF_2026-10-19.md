## 二、当前架构与自研接入点

```text
SC431HAI → CSI RX → 写入像素顺序修正 → 官方 v7 帧缓存/DDR → CVO
  → RAW 黑电平/固定白平衡 → BGGR 去马赛克
  → RGB 双像素流 ─────────────→ 原图固定延迟 ─┐
                 → 灰度 → 3×3 中值 → Sobel → 按帧号/坐标匹配
                                             → 五分区选择 → 原 HDMI 串行化/编码
```

核心接入文件是 [`rtl/v7_algorithm_video_pair.sv`](../_fpga_edge_agent/work/active/track4_v7_algorithm_bridge_001_20261018/rtl/v7_algorithm_video_pair.sv)，顶层是同工程 `rtl/ti60f225_oob_top.v`。六个复用算法位于 `algorithm/frontend/`：`frontend_frame_pair`、`rgb_to_y_pair`、`window3x3_pair`、`line_store_pair`、`median9_pair`、`sobel_pair`。

五个区域按原始 x 坐标各占 384 像素：颜色、灰度、中值、Sobel、原图加红色边缘。它们是同一完整帧的五个不同位置，不是五张缩小后的完整画面；因此不能用不同区域的不同物体直接定量比较中值效果。

灰度 `(77R + 150G + 29B + 128) >> 8`；中值使用 3×3、边界复制；Sobel L1 严格大于阈值 256 才算边缘。固定桥接延迟 4402 个 74.25 MHz 双像素时钟，约 59.29 μs。算法不向相机或显示施加回压；匹配结果缺失时回退原图，下帧重新建立状态。此五分区 bit 固定模式、固定阈值，尚无按键切换。

按键候选在 [`track4_v7_algorithm_control_001_20261018`](../_fpga_edge_agent/work/active/track4_v7_algorithm_control_001_20261018)：GRAY → MEDIAN → DIFF X8 → SOBEL → OVERLAY → SPLIT → COLOR。KEY0 保持 v7 复位，KEY1/KEY2 阈值 ±32，KEY3 切模式；20ms 消抖，帧边界生效。其完整说明和测试已归档，但尚无实机验收。

## 三、已找到的具体问题

1. **偏紫**：带明确行奇偶标签的 RAW 采样支持 BGGR 映射。校准采用黑电平 16，Q8 增益 R=317、G=256、B=582；早先四 Bayer 候选凭画面试错没有独立解决问题。白纸 02 过曝，不用于拟合。它是固定白平衡，不是自动白平衡；不同光源下的远处白色偏蓝仍可能存在。
2. **像素顺序**：实际打包/解包链仿真发现每四像素读出为 P2 P3 P0 P1，顶层写入排列补偿后恢复 P0 P1 P2 P3。官方 v7 来源及逐字节对照有独立报告；此问题不改变像素总数和 Bayer 奇偶，不能只靠 HDMI 分辨率或颜色正常排除。修正已进入算法基线。
3. **帧率混淆**：HDMI 配置为 1920×1080@60Hz，而独立 FPS 测量版的相机有效帧为 1920×1080、周期约 78.98886ms，即 12.660 FPS。后续 bit 没有复测，不能转写为实时相机 60 FPS。
4. **原自研版无图**：旧 031/refine 曾停在 DDR 阶段码 0x1F、只有彩条；目前通过保留官方 v7 采集/DDR/显示并迁入算法恢复功能。旧整机的根因没有完成受控对照和闭环。没有证据支持“完整重构 demo10 已定位所有根因”。

## 四、失败缩小版与下一步

[`DISPLAY-HALF`](DISPLAY_HALF_FAILURE_2026-10-19.md) 上板无信号。不要以“构建通过”覆盖这条实测失败，也不要向它继续叠加算法功能。若再做半尺寸，优先在保留标准 1920×1080 有效区和同步时序的 RGB 显示阶段进行缩放/居中填黑；RAW 上隔行隔列抽样还需处理 Bayer 相位。此处是后续设计方向，尚未实现验证。

建议接手顺序：

1. 用推荐 bit 恢复画面，记录文件哈希、五区实时与边缘对齐；本次回退确认仍缺失。
2. 在独立副本验收按键候选：每个模式实时、阈值数字和边缘响应一致、长按只触发一次、无错行停帧；必要时回退推荐 bit。
3. 复测当前整机采集 FPS、长时间运行及错误计数，再逐段迁入 Canny、冻结/重处理和识别。避免同时替换已经运行的 DDR、CSI 和显示链。
4. 若需要闭环旧自研无图，单独比较旧版和 v7 的复位、DDR 参数/时钟/约束、启动顺序和帧握手；先形成可复现最小差异，再判定根因。
