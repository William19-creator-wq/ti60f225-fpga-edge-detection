# 赛题四实施工作流

更新：2026-09-23。状态：需求分解和环境预检；尚无赛题功能通过硬件验收。

本项目覆盖赛题四基础任务和六项高阶挑战。高阶在赛题文件中属于拓展项，本项目全部纳入规划。这里的任务是工程交付，不含学习安排。正式要求和出处见 [需求追踪表](../requirements/TRACK4_REQUIREMENTS.md)。

## 共用节点规则

保留 H0–H5 的既有 ID，新增 A1–A6 和 R0，不重编号历史记录。每个功能节点都执行以下闭环：

1. 按[设计前置流程](../WORKFLOW.md)及[规范 v0.2](../../../AI_Agent_代码可理解性规范_增补提案_v0.2.md)调查基线；先明确整体外部行为、需求、模块职责/连接与相容接口，完成组合设计检查，再深入局部数据、状态、不变量、中文草图、时钟域、像素格式、数值/时间/配置契约和资源预算。
2. 使用[任务模板](../../planning/PLAN_TEMPLATE.md)保存版本化设计、验证计划与双向追踪；无当前阻塞且读回/呈现后标记 READY_FOR_REVIEW，等待用户批准该版本、范围和基线。批准前不生成 RTL、业务实现、功能脚本、可执行测试或 testbench；不得以子 Agent、代码块或原型绕过。原工作副本/工程/编译审批仍需分别满足，随后仅在 `work/` 实现批准范围并审阅差异。
3. 获批后做模块仿真和集成仿真，比较参考结果；检查复位、边界、计数、CDC、有效传输/停顿、配置变更、数据身份、同步延迟、位宽及溢出。未能运行的仿真标记未执行；设计变化按规范 §11 先修订复核，不能以改期望值掩盖实现偏差。
4. 运行获准的综合、接口检查、布局布线、时序分析和 bit/hex 生成；保存全部报告。工具退出成功不能替代时序、未约束路径和资源检查。
5. 产物登记包含源文件、IP、工程、约束、工具版本、构建日志和 SHA256；进入 `WAITING_HUMAN_PROGRAM`。
6. 人工下载，明确反馈下载结果后进入 `WAITING_HUMAN_OBSERVATION`；人工观察并提供现象、照片或视频引用。
7. 将反馈结构化为节点、构建、产物、测试条件、预期、实际、结论及证据；进入 `ANALYZING`，再判定 `PASSED / REWORK_REQUIRED / BLOCKED`。

Agent 不替人下载 FPGA、烧写 Flash 或操作调试器。各硬件节点都要独立闭环，不能用某次整机演示补签全部历史节点。没有观察时保持等待，不能把编译通过当硬件通过。只有 H0 是身份与环境确认节点，不要求生成 bit。

## 基础链路 H1–H5

| 节点 | 细化工作包 | 软件验证 | 人工验收 |
|---|---|---|---|
| H1_DISPLAY_BASELINE | 核对 HDMI 物理输出方案；像素时钟/PLL；行场时序；彩条、边框、棋盘；输出复位 | 行/场总长与有效区计数；SDC 时钟与路径；同步信号对齐；资源/时序 | 至少 640×480@60Hz；显示器识别、完整边界、稳定颜色，无闪烁/撕裂 |
| H2_CAMERA_STREAM | 相机供电/复位/参考时钟；I2C ID 和模式初始化；DVP 或 CSI-2 接收；RAW8/10 解包；必要的 Bayer/RGB 转换；CDC/FIFO；帧行像素计数；直通 | 寄存器与目标模式依据；包/行/帧边界；FIFO 溢出欠读；分辨率与坐标；采集和显示速率差异处理 | 有效画面与颜色；稳定无错位/丢帧；记录实际采集 fps、输出刷新率、光照和模式 |
| H3_GRAYSCALE | 固定点 RGB 灰度公式、量化/舍入；DSP 或移位加法；数据/valid/行场同步延迟 | 已知 RGB 向量；黑白极值；数值误差；不引入除法器；资源检查 | 灰度层次和方向正确，运动画面稳定 |
| H4_WINDOW_AND_SOBEL | 两行缓存；3×3 窗口；边界策略；Gx/Gy；绝对值与求和；流水线；参数阈值 | 常量、横/竖/斜边、脉冲和图像边界；有符号位宽/溢出；参考结果逐像素比较；输出坐标对齐 | 边缘位置和方向正确；无行首残留/错位；几何、数字、人脸轮廓样例 |
| H5_THRESHOLD_DISPLAY | 阈值二值化；灰度/边缘分屏或画中画；缩放/裁剪策略；模式与复位；基础集成回归 | 比较布局、延迟一致性、窗口边界；随机帧和连续帧；吞吐/FPS/时序/资源 | 稳定同时比较灰度与边缘；完成基础演示并保存视频和构建版本 |

60Hz 是最低 HDMI 显示要求，不是相机必须达到的帧率。分别测量采集帧率、算法有效处理帧率、显示刷新率。文档中的“零延迟”不得记为 0 周期，需测量行缓存和流水线引入的实际延迟。

## 高阶 A1–A6

基础先通过再集成高阶；下列顺序是工程建议，依赖允许且相应设计/工具审批有效时可先做独立仿真；不能因此先生成未获批的实现或 testbench。A1/A2/A5 不必等待 DDR，A4 的存储方案需专门设计。

| 节点 | 依赖与模块拆解 | 仿真/构建验收 | 人工验收 |
|---|---|---|---|
| A1_MEDIAN_FILTER | H3/H4；灰度后、Sobel 前增加 3×3 窗口与 9 值并行排序网络；旁路切换；同步延迟 | 参考中位数；重复值、全0/255、椒盐；全流水吞吐、时序/资源；明确窗口级联边界 | 同一场景旁路/滤波对比；噪声抑制与边缘保持 |
| A2_LIVE_THRESHOLD | H4/H5；核对实际按键/拨码；同步、消抖、单次脉冲；阈值寄存器及上下限 | 抖动、长按策略、同时按、复位、饱和不回绕；阈值变更时点 | 加阈值边缘减少、减阈值边缘增加；操作响应稳定，记录阈值 |
| A3_DDR_FRAMEBUFFER | H2/H5；实际 DDR 参数和 Efinity DDR 控制器 IP；校准；CDC/FIFO；帧地址/读写仲裁；缓冲所有权；冻结/恢复或回放 | 初始化/校准；读写一致；地址跨界；帧切换；欠读/溢出；带宽预算与实测、时序 | 无撕裂/错帧；冻结内容稳定、恢复正常；长运行与复位重入 |
| A4_CANNY | H4；高斯 → 梯度幅值/方向 → 非极大值抑制 → 双阈值 → 滞后连接；评估行/帧存储和连接迭代，必要时依赖 A3 | 逐级参考和最终参考；方向量化；弱边连强边、孤立弱边、长边链、交叉与边界；连续性、单像素宽、资源/时序/FPS | 与 Sobel 对照；连续轮廓与噪声控制；记录阈值与光照；不能以简化 Sobel 冒充完整 Canny |
| A5_COLOR_OVERLAY | H2/H4/H5；保留原始 RGB；RAW 相机需相应彩色处理；原图/边缘帧号、坐标及延迟匹配；红色等边缘覆盖 | 非边缘 RGB 不变；边缘色正确；像素/行/帧对齐；运动场景 | 彩色原图保留、叠加清晰，运动边缘无可见错位重影 |
| A6_SHAPE_RECOGNITION | H4 或 A4；轮廓/连通信息、几何特征、圆/矩形判别；位置与标签显示；选择算法并冻结测试集 | 目标/非目标；尺寸/位置/旋转/噪声；误检漏检；资源和处理帧率；标签/框对齐 | 圆形/矩形实物与负样例；显示识别结果，记录成功率与失败条件 |

TinyML/RISC-V 不是赛题四的必要条件。A6 先评估几何特征路线；若以后明确选择 TinyML，才另立模型、量化、Sapphire/BSP、自定义指令、资源预算和工具申请工作包。不得仅因资料中有 TinyML 就安装整套依赖。

## R0：集成、回归与交付

1. 冻结功能组合矩阵：基础、滤波开关、阈值范围、DDR 冻结/恢复、Sobel/Canny、彩色叠加、识别。逐项记录通过/失败/未测。
2. 统一资源预算：LUT/FF/BRAM/DSP、存储占用、时钟、吞吐、采集/处理/显示帧率、端到端延迟、峰值带宽。预算数值随目标模式确定，不伪造已达到的指标。
3. 长时间运行、按键/模式切换、复位恢复、静态/运动/暗光/噪声和图像边界回归。时长和测试条件在执行前确定。
4. 人工完成最终下载和观察；保留带节点/构建/产物关联的视频、结果和异常。无硬件反馈不得关闭发布节点。
5. 交付完整 RTL、约束、IP/工程配置、合法依赖说明、构建命令/版本/日志、SHA256、操作说明、演示视频与比赛报告；对照实际实现复核最终设计、中文注释、代码/测试与双向追踪。提供整体→连接→局部的阅读路径，功能验收与理解验收分别记录，没有用户作答不声称已经理解。

## 数据、工具与暂停恢复

每个工作包关联 project/session/turn/event/operation/node/artifact；构建、观察、审批和异常还关联 build/observation/approval ID。PostgreSQL 保存结构化索引，本地追加事件和报告保存证据。无产物阶段显式记为不适用，不伪造 artifact。

目前这些是工作流要求，不能当作运行时已强制实施。审批、状态转换、重复副作用拦截及恢复仍需运行时验收。工具、MCP、插件仅按实际缺口申请，列出名称版本、来源、目的、权限、网络、副作用、回滚和输出文件；批准前不得下载或安装。

暂停时保存最后通过的阶段、工作副本哈希、错误、待办及已产生的副作用；恢复先核对产物和账本，再重试失败阶段。不得不加区分地重复整套构建、设备操作或数据库写入。
