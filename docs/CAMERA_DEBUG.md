# 摄像头无应答与花屏调试

截至2026年10月14日，相机仍没有I²C地址应答；主板侧两根I²C线的慢速拉低、释放和数字回读已经实测通过。现有证据不能判定摄像头损坏，也没有证明控制信号经过排线到达传感器。

## 已确认的现象

| 测试 | 结果 |
|---|---|
| 官方HDMI TX彩条 | 显示器持续显示稳定彩条 |
| 031整机 | 黑屏，曾短暂识别分辨率，之后无信号/待机 |
| 官方SC431HAI到HDMI v7 | 彩色噪点，遮挡镜头基本不变；拔下相机仍有同类花屏 |
| CAM ID两个地址 | 7位0x30、0x32均在首个地址字节没有ACK，未读出3107/3108身份 |
| 换排线 | 身份探测灯态相同 |
| RST短时间高低对照 | 没有恢复ACK |
| Claude RST STATIC持续高低对照 | 两种外部RST电平下均无ACK/ID；D6约2秒闪一次表示持续尝试，不是ACK |

v7花屏可能由显示端继续读取尚无有效相机帧的数据造成；具体噪点来源未被证明。“官方v7”指用户提供的0927资料包中的原始bit，不是另行认证的网络下载版本。

| 测点 | 对地电压 |
|---|---|
| 相机C1 | 4.906V／0V |
| 相机C6 | 1.22V／0V |
| 相机C2 | 2.798V／0V |

| 外部RST低时TP1／TP2 | 0.03V／0.55V |

TP1、TP2没有明确网络标注，不能当作芯片RST、SCL或SDA的直接测点。供电电压存在也不能证明复位、时钟或通信时序正确。早先R221约0.24V压降不是已确认空闲状态，后续已知空闲时两电阻均约0.3mV压降；不能保留“只有SCL接到了相机”的旧推断。

## 2026年10月14日慢速电平试验

对应bit：`track4_camera_bus_level_001_20261013/outflow/ti60f225_oob.bit`，SHA256 `BE725FFEC88014BC33105396E54210449C818791963F44FB570075060183E4BA`，Programmer校验值 `2057AA9B`。11:15:46日志确认进入user mode且下载完成；只使用临时JTAG，没有烧写Flash。

| 阶段 | 用户报告 |
|---|---|
| D2亮，只拉低SCL | R221两端3.3V、0.06V |
| D3亮，两线拉低 | R222两端0.062V、3.3V |
| D4亮，释放SDA | R222两端3.3V、3.3V |
| D5亮，已结束 | D6、D7均灭；R221两端都3.3V |

这轮检查证明主板测点处SCL/SDA均能拉低并恢复高电平，有限序列正常结束且未留下回读错误。它没有发送地址或寄存器事务，不能证明动态I²C波形或ACK，也不能证明相机端连通。

这一版D1至D4表示阶段、D5表示结束、D6表示SDA错误、D7表示SCL错误；与ID版和RST STATIC版的灯义不同。按SW0可重跑慢速检查，但不能借此改变原版本的灯义。

证据入口：[观察目录](../_fpga_edge_agent/observations/structured)、[BUS LEVEL审计](../_fpga_edge_agent/reports/audit/camera_bus_level_001_20261013)、[最新设计及测量实录](../_fpga_edge_agent/planning/design-TRACK4-CAM-BUS-LEVEL-001.md)。

## 已核对的主板引脚

| J4网络 | FPGA球位和GPIO |
|---|---|
| pin2 SDA | B14／GPIOR_18，3.3V LVCMOS |
| pin3 SCL | D12／GPIOR_20，3.3V LVCMOS |
| pin6 Sensor RST | C12／GPIOR_16，3.3V LVCMOS |
| pin1、pin5 | 模组5V输入 |
| pin4、pin7 | GND |

R221为SCL、R222为SDA，均4.7k上拉到主板3.3V。相机模组内部的电平转换、RST极性与晶振网络仍需模组资料或实际测量，裸芯片手册不足以代替。

## 下一步

优先借同型号相机或另一块已知正常V4板做断电替换对照。若只有当前设备，向供货方索取模组J1定义与SCL/SDA/RST/EXTCLK测点图；确认后使用细针表笔断电查连通，再检查相机端电平和动态波形。现有普通粗表笔不适合直接碰J1/J4细小焊脚。

完整调试恢复ACK之后，才继续帧计数、RAW10、DDR帧数据、HDMI和算法效果验收。
