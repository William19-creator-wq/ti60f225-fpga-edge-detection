## B. 整体行为、例子与结果含义

R1：FPGA全局复位期间沿用原RST高电平，I2C释放。全局复位同步释放后，先将J4 RST保持低至少20ms，探测器保持复位；然后RST拉高，才释放原CAM-ID探测器。探测器自身再等待至少20ms后只执行原四笔3107/3108读取，地址仍为0x30、0x32。

R2：正常/普通NACK完成后锁存D1–D7结果，停止探测器，保持RST高且本机SCL/SDA释放至少1ms，再将RST恢复原运行低电平，进入终态。恢复低会改变传感器状态，但锁存结果不变；屏幕不参与验收。

R3：原探测器报告故障，或外层从同步释放起超过500ms名义期限，则锁存已有ACK/完整ID资格，D7置1、D6清0；立即禁止本机驱动和新事务，经同样1ms安静阶段恢复RST低。外设仍拉低时不宣称总线已恢复。不循环、不自动重试；SW0全局复位或新配置才重启一轮。

R4：沿用CAM-ID v1灯义：D0原DDR校准心跳；D1已开始读；D2/D3=0x30地址ACK/完整CD6B；D4/D5=0x32地址ACK/完整CD6B；D6四笔已安全结束（普通NACK也算）；D7故障。等待阶段新灯为0，探测阶段可显示实时标志，完成后只显示锁存快照。不能把“结束后RST恢复低”误解为这些灯对应低电平读到的结果。

R5：只复用原请求/回复/ACK/ID资格；不把错误读值、未完整读取或单字节有效当成功。任何一次比特流成功下载都必须与人工灯态分开记录。

样例：高电平阶段0x30返回CD6B、0x32普通NACK，则结束后D1/D2/D3/D6亮，D4/D5/D7灭；两地址NACK则D1/D6亮，其他新灯灭；超时则D7亮、D6灭，已经获得的ACK/完整ID证据可保留。高条件成功只能证明该次外部状态下通信成功，低/高都失败不能定位坏件。

## C–D. 模块、接口与组合检查

整体：原core_clk/w_arstn → M1限时监督 → IF2原ID探测M2 → IF3单一开漏I2C → J4；M1注册RST电平 → IF4原J4 pin6；M1结果 → 原LED。

| 模块/计划文件 | 职责与接口 |
|---|---|
| M1 新 `rtl/cam_id_probe/camera_reset_compare.sv` | 输入clk、arst_n、scl_i、sda_i均1位；输出cam_rst_p、scl_drive_low、sda_drive_low及原7个灯标志均1位。拥有阶段、计时、探测器reset资格、结果快照；不实现位级I2C |
| M2 原 `camera_id_probe.sv` + master/pkg | 原样复用；只在RUN_HIGH获得释放资格。地址/tag/停止/读资格继承CAM-ID v1设计，不修改源码 |
| M3 `rtl/ti60f225_oob_top.v` | 将原探测实例替为M1；原RST赋值替为M1输出，删除旧驱动以保证唯一驱动；保持原D0及其他视频路径 |
| XML | 仅增加M1源文件，保持pkg→master→probe→supervisor顺序及既有调试流程 |

IF1：100MHz上升沿；M1对w_arstn采用异步置位、两级同步释放，内部状态同步清零。外层异步复位时强制RST高、I2C释放、M2保持复位；解除后等待同步链，不能异步接受事务。

IF2：M2的arst_n由全局资格及RUN_HIGH资格门控，其他阶段为0。低保持结束时先注册RST高并进入RUN_HIGH；M2经自己的两级同步释放再开始20ms等待。M1读取M2稳定标志；观察到all_done的边沿已经晚于M2对末字节/ID资格的提交，不会读旧ID。停止时M1同沿锁存旧的完整结果，随后M2复位清零，不影响快照。

IF3：仅RUN_HIGH且未触发强制截止才允许M2拉低资格到顶层；OUT仍固定0，OE仍原正向驱动资格。QUIET/FINISH/复位均立即关闭驱动；硬件电气配置及异步输入同步器保持原样。

IF4：RST使用寄存的正常电平，不组合译码多位状态产生毛刺；全局复位优先使其高。LOW_HOLD=低，RUN_HIGH/QUIET=高，FINISH=低。不触碰裸芯片引脚，不使用外部供电。

组合检查：只有一个读引擎，无相机配置引擎竞争；M1不会在有效事务中普通切换RST。正常结束要求M2四笔均返回已释放结果；故障路径先终止本机驱动再延时回原RST。状态与结果同域，不引入多位CDC；结果快照隔离复位清零。原DDR/MIPI不参与探测资格。

## E–F. 中文步骤与RTL契约

状态为LOW_HOLD、RUN_HIGH、QUIET、FINISH（2位）。数据：低保持计数21位（2020000拍），安静计数17位（101000拍），外层期限计数26位（50500000拍），结果7位；全部无符号、饱和不回绕。按101MHz上界计算，实际100MHz分别约20.2ms、1.01ms、505ms；外层期限不延长已经开始的QUIET。

1. 同步复位清计数、快照和阶段，禁止M2；RST在复位资格内高。开始有效时进入低保持并注册RST低，该首次变低边沿低保持计数置0，后续计满2020000个完整周期后提交RUN_HIGH和RST高。
2. RUN_HIGH放行M2，四笔时序完全沿用M2。先根据旧状态/旧计数判断截止，再采样完成/故障。故障与完成同沿时故障优先；期限同沿出现安全all_done且无故障时允许正常完成，否则归超时。
3. 进入QUIET时锁存M2的开始、ACK、完整ID标志；正常结束保留all_done，异常则强制D6=0、D7=1。立即禁止M2和两线拉低资格；RST仍高，计满101000拍再注册RST低并进入FINISH。
4. FINISH不推进计数，不生成事务，持续显示锁存结果。非法阶段按异常收尾：禁止驱动、记录故障、经QUIET恢复低，不继续尝试。全局复位优先于所有上述步骤，并使旧结果作废。

RTL A–L：A数值/边界如上；B所有内部状态posedge/core_clk、NBA提交；C外部无流输入，M2原valid/ready事务不改；D无ACK与未运行区分，状态计时不依赖ACK；E M2反压/正文保持不改；F名义最多500ms加1ms收尾（实际约506.01ms及少量同步周期）；G复位/在途取消如IF1–3；H仅静态配置，无运行时寄存器修改；I仅寄存器计数/快照，0RAM；J地址/tag身份及完整ID沿用M2，快照绑定高电平阶段；K输入同步器沿用、M1新增复位同步链；L Efinity2026.1.132/SV2009/Ti60F225/I3，100MHz，M1新增预算<250LUT/<150FF、0RAM/0DSP，以构建报告核实。时钟停振时不保证墙钟期限，D0心跳及工具时序不替代该条件。

C++/跨语言模型N/A：本实验不生成C++或数值算法，只做RTL监督和外部身份读取。继承原SDC限制，不以新false-path掩盖失败。
