正常语义示例：先写入字节 0x12，再写 0x34，对应读出 0x1234（ENDIANESS=0）；仅说明端序，不声称既有随机激励必然出现这组值。有效零数据必须比较；valid=0 时即使总线为零，也不能计作有效读取。

### M2：刺激与参考比较

局部数据：wdata 为当前待写字节；dynamic_a 是尚未读取的历史写入字节队列，初始化空，按接受事件入/出；monitor 是本次读取的 16 位参考值，在读接受上升沿以非阻塞赋值更新。dynamic_b 是厂商其他模式参考路径保留的队列；本次 STANDARD 分支不要求它最终为空，不改它。waddr/raddr 为原示例地址计数器，分别 9/8 位，会在最后一次接受后自然回绕；不把它们的末值当总事务数。

不变量：复位等待期间请求为 0；有效写入按顺序入 dynamic_a；每次有效读取消耗两个字节，高字节先入；参考数据与 FIFO 接受事件一致；只有 valid 时比较。总计数从日志及波形接受事件独立核对，不能靠循环次数声称已接受。

中文步骤：

1. 原 TB 初始化复位为 1、请求为 0、队列为空；1080 ns 后释放外部复位。把现有“复位低且 busy 高时启动”的等待条件改为“复位低且 busy 低”，保留后续 10 个写时钟下降沿等待。busy 来源为 wr_rst_int 与 rd_rst_int 的或，两个复位同步器使用高有效复位。
2. 保留原 512 次下降沿写激励；每次更新 wr_en 和 8 位 wdata，下一上升沿按当时 full 决定是否接受。参考队列同沿基于当时输入和旧状态记录；信号后续变化不能追溯为该沿已接受。
3. 保留 2 个下降沿写请求关闭间隔，再发 256 次读请求；读接受上升沿按旧 empty 判断，顺序弹出两个历史字节组为 monitor，在非阻塞更新后供下一下降沿比较。
4. STANDARD/OUTPUT_REG=0 分支在读时钟下降沿且 rd_valid=1、外部复位为 0 时比较 rdata 与 monitor；保留原比较器，另由 M3 排除双方均含 X/Z 的假通过。无效输出忽略，空 FIFO 不消耗参考数据。
5. 关闭读请求，保留原 2 个间隔与 10 个结束下降沿，再由原 TB 的 $finish 结束。禁止提前结束后只保留若干 PASS。

时钟连接保持原样：wr_clk 周期 14 ns，wr_clk_i 与 rd_clk_i 都接它。另一个周期 18 ns 的 rd_clk 虽被创建，却未连接 FIFO。**因此本次不是异步时钟测试。** 数据使用原 $random 激励；该表达式的 32 位随机返回值经重复拼接后赋给 8 位 wdata，保留低 8 位，不是仅重复一个随机位。保持表达式不改，沿用厂商测试台未显式传 seed 的方式。完整记录实际 512 个已接受字节及版本，供顺序/数据复查；本次通过条件不依赖某个特定随机序列，不宣称跨进程确定性或全数据覆盖。

观察时刻依据：`efx_fifo_ctl.v` 在本次 OUTPUT_REG=0 分支的读上升沿将 rd_en_int 更新到 rd_valid；`efx_fifo_ram.v` 在同沿以非阻塞赋值更新 rdata_1P；TB 的 monitor 也在该沿更新。因此当前配置的下一下降沿比较在这些更新之后，不把尚未调查的延迟当成假设。

| C 接受/交付 | 写：wr_en 且非 full；读：rd_en 且非 empty；均在复位完成后的对应上升沿。交付/检查：rd_valid 有效的下降沿；无 ready 端口 |
| D valid/推进 | 参考队列按接受推进；比较次数按有效交付推进；valid=0 时总线任意，不等于数值零；X/Z 的 PASS 不接受 |
| E 反压/保持 | 本例不做动态停顿压力测试；满/空阻止接受。若固定激励被阻挡造成事务不足，本次失败而非丢弃后宣称通过；数据在驱动下降沿至接受上升沿间保持 |
| F 延迟/吞吐 | 保留厂商 STANDARD/OUTPUT_REG=0 的比较时序；每次读接受在上升沿构造参考，随后的下降沿仅在 valid 时检查；PIPELINE_REG=1 不自行换模式或延迟。内部实现延迟不作为独立性能认证，观察到错拍先停止复核 |
| G 复位 | 外部高有效，内部两域复位由现有同步器处理，rst_busy 为二者的或；两者低再等 10 个下降沿。无中途复位；不要求 RAM 物理清零，以空标志/有效性隔离旧数据 |
| H 配置 | 静态生成参数，生成/展开前冻结；无运行期写配置、无同沿配置事务，无跨域配置更新 |
| I 存储 | 512×8 位写容量等价 256×16 位读容量；先写后读；不覆盖同时读写/同址冲突；参考队列最多 512 个字节；满空保护启用 |
| J 身份 | 第 2k、2k+1 个已接受写字节对应第 k 个读结果的高/低字节，k=0…255；无图像帧行坐标、颜色或 last 信号 |
| K CDC | 参数 SYNC_CLK=0、SYNC_STAGE=2 保持；实际两输入钟同源，仅验证模型运行，不验证异步相位/频率/亚稳态；CDC 验证另立任务 |
| L 实现 | 使用厂商 SystemVerilog 示例与 FIFO 8.1 模型、当前 Questa2024.1；无综合资源/时序签核。本次只允许列明参数组合，不泛化边界参数正确性 |

C++ 不适用：未涉及 C++ 代码、对象、异常、分配或模型。跨语言共同数值/硬件映射三份契约不适用：无 C++ 参考结果参与；RTL 内部数值与硬件事件已经分别列于上表。Python 仅为生成控制适配，沿用现有 API，不实现业务算法；输入是检查后的 W 路径和冻结配置，输出是生成状态/清单，错误不得静默吞掉，子进程只继承所需既有环境，外部副作用限于 W/R。
