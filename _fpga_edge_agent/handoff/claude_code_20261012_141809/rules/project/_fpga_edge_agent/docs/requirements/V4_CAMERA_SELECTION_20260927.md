## 其他相机的适用性

1. **IMX219 彩色 MIPI**：可作为备选，有新增 HDMI 工程和 CSI2QSE 子卡原理图。但该工程 XML 记录 2024.2.294、C4，顶层含 24/25MHz 输入，与 V4 参考的 I3、25/27/50MHz 配置不同。须核实工程原始载板并移植约束/时钟/DDR；不能直接上板。常规 Raspberry Pi Camera Module 2 为 IMX219，官方资料不代表其与此 V4 板直接兼容。
2. **OV5640 / SC1336 彩色 DVP**：赛题允许 DVP，但此前示例是 VF 平台。当前 V4 资料没有核实可直接使用的对应套件，除非提供方交付 V4 专用接线和完整工程，否则暂不作为首购建议。
3. **SC2210 彩色 MIPI**：相机本身是候选，但 VF 工程、相机接口和初始化不能直接套入 V4 的 SC431HAI 链路。
4. **AR0135 / SC130GS 黑白 SKU**：可验证灰度边缘，但不能作为真实彩色输入和原彩色边缘叠加的唯一相机。
5. **USB/网络摄像头、只有裸传感器的器件**：不属于当前已配套的 MIPI 输入模组路径。

## 采购类别与必须匹配的信息

- 类别：面向 FPGA 的可见光彩色 CMOS 摄像头模组，优先当前 V4 配套 SC431HAI；自带镜头与所需供电电路。
- 输出：MIPI CSI-2；优先与现有示例匹配的 4 data lanes，RAW 格式、位宽及 Bayer 顺序由实际初始化和模组确认。
- 接口：配套的 22 针定义、间距、接触面、排线正反、lane 顺序/极性和控制电平；若需转接板，要求同时交付原理图。
- 电源：兼容 V4 模组接口；不能只按传感器数据手册中的核心电源购买或接线。
- 图像：至少 640×480；可从已存在的 1920×1080 配置起步，再根据处理资源确定裁剪/缩放。HDMI 的至少 60Hz 与相机实测 fps 分开验收。
- 光学：普通可见光彩色款、适合桌面拍摄距离、可调焦镜头优先；不为当前纸张/几何图形演示强制购买高速全局快门型号。
- 资料：模组原理图/引脚表、完整初始化、对应 CSI/DDR/HDMI 源码、约束、Efinity/IP 版本、可复现编译说明。

向提供方确认是否随借用套装附带相机；不能把此前截图“摄像头 ¥100”当作已经确认的 SC431HAI 型号或最终报价。

## 2026-09-27 补充：一只相机在 VF 与 V4 两板间复用

在“允许不同转接板和分别适配 FPGA 工程”的前提下，IMX219 标准彩色 Camera Module 2 是优先核对的共用候选；尚无已验证的两板即插即用组合。当前只求 V4 最快打通，仍优先配套 SC431HAI。

- `Demo/Demo` 中的核心板和按键底板 PDF 与 VF HDK 对应 PDF 的 SHA256 分别完全一致，说明新增 Demo 混有 VF 平台资料。IMX219 工程的 24/25MHz 时钟、C4 设置也与 VF 参考一致；这支持其与 VF 平台有关的判断，不代表已经上板验证。
- IMX219 ZIP 的 CSI RX 配置为 2 data lanes、IP 5.7。顶层仍保留 SC2210 的旧模块/变量名，但被调用的初始化表包含 0x0114、0x016C–0x016F 等寄存器，I²C 地址字节为 0x20；不能只按旧文件名判断相机型号。
- V4 包有 `子卡原理图/CSI2QSE_MIPI.pdf`，标注树莓派 Sensor，使用 15 针 FPC；它提供转接设计依据，不表示借用套装包含该子卡，也不表示 V4 工程已完成 IMX219 适配。
- VF 手册 PDF p18 明确 MIPI RX/TX 需要转接板。两板分别需要适配该相机模块的连接、电源和工程；相同 Ti60F225 器件不消除引脚、时钟及 DDR 的差异。
- Raspberry Pi 官方定义标准 15 针相机口为 3.3V（Pin 15）；V4 配套 Sensor 22 针表为 Pin 1/5 的 5V。这些接口定义不同，普通树莓派 15转22 排线不能据针数直接用于 V4 的 Sensor 插座。核对供电、引脚、lane、接触面及必要电平转换后再连接。

候选范围：IMX219（共用路径优先核对）、SC431HAI（V4 已有参考、VF 待适配）、SC2210（VF 已有参考、V4 待适配）。未将任何候选升级为已确认的硬件基线。
