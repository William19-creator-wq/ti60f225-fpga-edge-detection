Sobel 核按资料为：

```text
Gx = [-1,  0, +1; -2, 0, +2; -1, 0, +1]
Gy = [-1, -2, -1;  0, 0,  0; +1,+2, +1]
G  = abs(Gx) + abs(Gy)
```

## 六项高阶挑战

### T4-A1：中值滤波去噪

- 状态：`PLANNED`。节点：`A1_MEDIAN_FILTER`。来源：S1 p14–15；S2 p26。
- 要求：在灰度之后、边缘检测之前插入 3×3 中值滤波；9 个像素排序取中位数；抑制椒盐噪声；合理设计排序网络，避免串行排序。
- 工程依赖：`H3_GRAYSCALE`、`H4_WINDOW_AND_SOBEL` 的窗口和同步基础；滤波加入后的总延迟重新计算。
- 建议验收：比较器网络对照参考排序，包含重复值、全 0、全 255、椒盐噪声；检查边界、吞吐、资源和时序；同输入旁路/滤波结果对照与人工观察。

### T4-A2：实时阈值调节

- 状态：`PLANNED`。节点：`A2_LIVE_THRESHOLD`。来源：S1 p14、p17；S2 p26。
- 要求：用板载按键或拨码实时调整 Sobel 阈值；加阈值时边缘减少、减阈值时边缘增加；有消抖模块和阈值寄存器。
- 工程依赖：`H5_THRESHOLD_DISPLAY`；实际按键引脚、电平和时钟域得到确认。
- 建议验收：消抖、单次响应、阈值边界饱和及复位仿真；保留阈值变化记录；人工操作与屏幕效果视频。

### T4-A3：帧缓存与 DDR 控制

- 状态：`PLANNED`。节点：`A3_DDR_FRAMEBUFFER`。来源：S1 p14；S2 p26。
- 要求：完整帧写外部 DDR，实现采集、存储、读取、处理分离；可提供回放、帧冻结、多帧对比等功能。S1 另明确调用 Efinity DDR 硬核控制器 IP；S2 的简化页面没有这句，不视为取消。
- 工程依赖：`H0_BASELINE` 的实际 DDR/时钟/引脚/IP 信息，以及 `H2_CAMERA_STREAM` 和 `H5_THRESHOLD_DISPLAY` 的数据与显示链路；明确帧地址、FIFO、跨时钟及读写调度。
- 建议验收：控制器/IP 配置、初始化或校准结果、整帧读写一致性及带宽；记录选定交互功能（例如冻结/恢复）的人工验证。只复用含 DDR 的示例不自动等于挑战已验收。

### T4-A4：Canny 边缘检测（算法升级）

- 状态：`PLANNED`。节点：`A4_CANNY`。来源：S1 p14；S2 p26。
- 要求：完整实现高斯滤波 → 梯度幅值和方向 → 非极大值抑制 → 双阈值分类 → 滞后边缘连接，获得更精确、连续的单像素边缘。
- 工程依赖：基础图像链路、邻域及方向处理、各级延迟对齐、强/弱边缘状态与连接方法。是否使用 DDR 必须由架构分析确定；文档未规定 A3 是 A4 的硬依赖。
- 建议验收：每级参考数据和端到端黄金模型；弱边连接强边、孤立弱边、长链、交叉、边界案例；连续性与单像素边缘；Sobel/Canny 对照及实测资源、时序、帧率。缺少滞后连接时不能宣称完整 Canny。

### T4-A5：边缘叠加彩色输出

- 状态：`PLANNED`。节点：`A5_COLOR_OVERLAY`。来源：S1 p14；S2 p26。
- 要求：以彩色边缘线（例如红色）叠加到原始彩色图像，处理 RGB 三通道叠加逻辑。
- 工程依赖：`H2_CAMERA_STREAM`、`H4_WINDOW_AND_SOBEL`、`H5_THRESHOLD_DISPLAY`；保留原始彩色路径；若相机输出 RAW，需确认解包与去马赛克；彩色与边缘帧、坐标、延迟一致。
- 建议验收：非边缘原始 RGB 保持、边缘颜色正确、运动边界无重影；仿真延迟/坐标检查与人工视频。

### T4-A6：简易目标识别（创意拓展）

- 状态：`PLANNED`。节点：`A6_SHAPE_RECOGNITION`。来源：S1 p14–15；S2 p26。
- 要求：基于边缘识别圆形、矩形等特定形状；可采用轮廓与几何特征匹配；在屏幕显示识别结果。
- 工程依赖：`H4_WINDOW_AND_SOBEL` 或完成后的 `A4_CANNY`，轮廓/特征与决策逻辑，`H5_THRESHOLD_DISPLAY` 的显示标注能力；不强制 TinyML、RISC-V 或神经网络。
- 建议验收：标注图像和实物样本，包含目标/非目标、尺寸/位置/噪声变化；记录误检漏检及实际处理 fps；人工演示屏幕标签与物体对应关系。

## 解释边界与资料歧义

1. **中值滤波分类**：S1 p12、S2 p24 的概述包含中值滤波；正式基础清单未列，正式高阶 A1 列出。基础先打通 Sobel，A1 保留在规划中。
2. **显示与采集速率**：640×480@60Hz 是 HDMI 显示要求。赛题四未明确规定采集 fps 最低值；采集、处理、输出刷新分别记录，不能互相代替。
3. **“零延迟”**：S1 p12/p15、S2 p24 的说法表达行流水线实时性；两行缓冲和流水线必然引入延迟。记录实际行/像素/周期或时间延迟，不把 0 周期当验收值。
4. **性能提示不是验证结果**：S1 p15–16 的 220MHz 和典型 5 周期中值输出是技术提示，未给本项目实现证据，不能标成必达值或已达成。
5. **HDMI/VGA**：任务概述两者皆可，基础细项明确 HDMI。VF 参考路径以 HDMI 为优先基线；MIPI 屏不是赛题四必需。
6. **推荐平台与允许平台**：S1 p4 写 VF-Ti60F225 用于赛题四/自由选题，S2 p8 对应赛题四；S2 p29 Q&A 又说不强制指定开发板、Ti60 芯片可做赛题 1–4。保留不同表述，不把推荐板等同唯一允许平台。
7. **相机选择**：S1 p4 推荐 SC431HAI，赛题四正文允许 DVP 或 MIPI；没有将 SC431HAI 指定为本赛题唯一相机。不能直接把另一块板的 SC431HAI 引脚、电压、lane 或配置移植到 VF 板。
8. **TinyML/RISC-V**：S1 p9–11、S2 p21 在赛题三明确列出；赛题四正文没有必需条款。作为可选技术资料登记，不把安装其工具链作为基础链路的阻断条件。A6 可用几何特征匹配完成。
9. **器件资源措辞**：S2 p7–8 的平台简介称集成 RISC-V/NPU；S1 p3、p9–10 使用支持/部署 RISC-V 软核的说法。实际 Ti60F225 硬核与软核资源须以器件和 IP 文档确认，不据简介断言自带硬 RISC-V/NPU。
10. **软件版本与历史构建**：这两份赛题文档没有规定本项目必须用 Efinity 2026.1。版本选择必须记录示例版本、实际安装版本和兼容性检查；参考工程历史通过状态不证明当前编译和上板通过。
