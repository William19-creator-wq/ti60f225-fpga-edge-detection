## 4. 每项需求的状态

每项需求只用以下五级，按证据逐级上升，不跳级：

`未做` → `代码有` → `编译通过` → `实物通过` → `已录影`

- `编译通过`：必须对应一个具体 run，且综合、布局布线、最终时序都通过，并有 bit。
- `实物通过`：只能由用户的实际观察确定。
- 目前 B1–B4、A1–A6 的最高状态都是 `编译通过`（031），B5 为 `未做`。

## 6. 可讲解性要求

交付版本只写**一份**设计说明，不再每次修改产生一份设计书。内容：
- 整体模块图与数据流；
- 每个模块的输入、输出、参数、算法和延迟；
- 为什么这样划分模块。

讲解深度分两层：
- 灰度 → 中值 → Sobel/Canny → 阈值 → 叠加：要讲透，对应用户学习路线 L1、L3、L4；
- 相机、DDR、HDMI：讲到接口层级。
