# 状态机

## 任务设计标签（仅文档，不是运行时枚举）

按[规范 v0.2 §2/10/11](../../AI_Agent_代码可理解性规范_增补提案_v0.2.md)，在 `planning/design-<task-id>.md` 内记录：

`DISCOVERY → GLOBAL_DESIGN → LOCAL_DESIGN → READY_FOR_REVIEW → APPROVED_FOR_IMPLEMENTATION → IMPLEMENTING → VERIFYING → DELIVERED`。

每次转换写依据。关键未知进入 BLOCKED；已批准边界发生变化进入 DESIGN_REVISION，修订后重新评审。READY_FOR_REVIEW 只表示设计已呈现待评审；用户批准必须绑定版本、实现范围、基线和条件。DELIVERED 不能掩盖未做的硬件或理解验收。

这些标签不加入现有运行时/数据库 Schema，不写入 `state/PROJECT_STATE.json` 的 `state`，也不声称已有校验器强制执行。设计批准是生成业务源码/可执行测试/testbench 的前置条件；下方 SOURCE_APPROVED 仍是原节点的源码/工作副本审批，BUILDING 还要另有编译授权。两类批准都不能替代人工下载/观察。细节见 [WORKFLOW.md](WORKFLOW.md)。

## 项目状态

- `WAITING_FOR_HARDWARE_BASELINE`
- `READY`
- `PRECHECKED`
- `SOURCE_APPROVED`
- `BUILDING`
- `ARTIFACT_READY`
- `WAITING_HUMAN_PROGRAM`
- `WAITING_HUMAN_OBSERVATION`
- `ANALYZING`
- `PASSED`
- `REWORK_REQUIRED`
- `BLOCKED`
- `SUSPENDED_FOR_APPROVAL`
- `RECOVERY_REQUIRED`

## 合法转换

```text
WAITING_FOR_HARDWARE_BASELINE -> READY
READY -> PRECHECKED
PRECHECKED -> SOURCE_APPROVED
SOURCE_APPROVED -> BUILDING
BUILDING -> ARTIFACT_READY | BLOCKED
ARTIFACT_READY -> WAITING_HUMAN_PROGRAM
WAITING_HUMAN_PROGRAM -> WAITING_HUMAN_OBSERVATION
WAITING_HUMAN_OBSERVATION -> ANALYZING
ANALYZING -> PASSED | REWORK_REQUIRED | BLOCKED
REWORK_REQUIRED -> PRECHECKED
BLOCKED -> SUSPENDED_FOR_APPROVAL | RECOVERY_REQUIRED
SUSPENDED_FOR_APPROVAL -> PRECHECKED | RECOVERY_REQUIRED
RECOVERY_REQUIRED -> PRECHECKED | BLOCKED
```

禁止跳过人工下载和人工观察状态。数据库、审批、工具权限或硬件身份异常时进入 `BLOCKED` 或 `SUSPENDED_FOR_APPROVAL`。
