## B. 整体外部行为

R1：下载后的有效复位释放只执行一轮。整个实验只有新模块控制SCL/SDA，OUT固定0、OE=1拉低、OE=0高阻。外部相机RST沿用原运行低电平；系统复位期间为高。不假定模组内部极性已知。

R2：正常序列为四个测量阶段，每阶段按101MHz上界计30秒，100MHz实钟下30.3秒：

| 阶段/灯 | 本机SCL | 本机SDA | 主板信号端预期电压 |
|---|---|---|---|
| IDLE / D1 | 释放 | 释放 | SCL/SDA接近3.3V |
| SCL_LOW / D2 | 拉低 | 释放 | SCL接近0V、SDA接近3.3V |
| BOTH_LOW / D3 | 拉低 | 拉低 | 两信号端接近0V |
| SDA_RELEASE / D4 | 保持拉低 | 释放 | SCL接近0V、SDA接近3.3V |

每阶段先等待5ms以上电气稳定（100MHz下5.05ms），再检查两级同步回读。最后先保证SDA已释放，再释放SCL，等待至少1ms检查两线回高，进入吸收终态。正常SDA变化只发生在已验证为低的SCL阶段，不主动生成START、地址/数据或寄存器写入。

R3：初始任一线非高，记录对应错误并安全收尾；SCL_LOW未回读低时禁止进入BOTH_LOW；后续拉低阶段发现SCL回高也中止。BOTH_LOW SDA仍高或SDA_RELEASE仍低时置SDA错误，保留该30秒测量窗口（SCL仍须低）再收尾，以便万用表观察。

R4：D0保留原DDR校准心跳；D1–D4为互斥的当前阶段，收尾/终态均灭；D5表示本轮已结束（含故障结束），D6=曾出现SDA预期不符，D7=曾出现SCL预期不符。结束不代表通信成功；LED和DMM报告要按这一版的新定义理解。

R5：新诊断复位输入明确使用 i_arstn && w_arstn：SW0按下可直接异步撤销本机驱动，不再只依赖PLL LOCK。两级同步释放后开始等待阶段。运行测量时不按SW0；意外复位只释放本机，不保证外部设备已释放。复位释放时可能产生STOP边沿，但不主动生成配置事务。

R6：正常轮约121.2秒加收尾；单阶段计数饱和/到期推进，FAULT也有限收尾，不自动循环。纯寄存器模块预算≤512 LUT、256 FF，0 RAM、0 DSP；最终以实际报告为准。

样例：理想开漏总线四阶段均匹配，终态D5亮、D6/D7灭。SDA OE断开且输入一直高：SCL正常，D3期D6置位，D5完成，不误报ACK。SCL OE断开：D2检查失败，D7置位，永不使能SDA拉低，安全收尾。相机拔下且板端上拉有效时电平检查仍可通过，不能推断相机端连通。

## D. 接口与组合检查

| IF | 端口/语义及前提 |
|---|---|
| IF1 | clk=100MHz core_clk；arst_n为1位低有效异步复位条件。两个复位释放FF共同控制M1同步初始化；不把SW0与LOCK当作同一信号。 |
| IF2 | scl_drive_low/sda_drive_low：1位、1=本机拉低资格。顶层OUT始终0，OE唯一来源为此输出；异步复位立即屏蔽两路资格。RST输出沿用~诊断有效复位条件。 |
| IF3 | scl_i/sda_i：1位异步引脚回读，经各自两级同步。阶段开始后先等待5.05ms再判断，避免沿前值误判；first-stage metastability属于硬件限制，内部同步级仍检查时序。 |
| IF4 | phase_leds[3:0]一热或0，finished/sda_error/scl_error各1位；顶层映射D1–D7。无多位CDC、valid/ready、帧身份或FIFO。 |

正常路径顺序保持：先验证空闲→仅拉SCL并验证→改变SDA→在SCL低时释放SDA→释放SCL。若SCL未低不允许拉SDA；不能靠源码drive_low代替引脚回读。错误位只累积，复位清零；DMM高/低是人工测值，数字回读符合不替代模拟电压或相机端波形。

## E. 局部中文操作草图

1. 异步复位立即撤销GPIO驱动；两级释放期间不开始计时。进入同步初始化时清阶段计数、两位错误和finished，设IDLE。
2. IDLE按32位无符号计数计满一个测量阶段；稳定等待满5ms后确认两线高，不符合则记录对应错误并进入安全收尾。
3. 进入SCL_LOW时只给SCL拉低资格并清计数；稳定后确认SCL低/SDA高，SCL不低则立即收尾，不允许进入BOTH_LOW。通过后保留30秒测量窗口。
4. BOTH_LOW保持SCL资格并给SDA拉低资格。稳定后SDA仍高则置SDA错误，但保留测量窗口；SCL回高则撤销SDA资格并收尾。期满进入SDA_RELEASE。
5. SDA_RELEASE只撤销SDA资格、保持SCL低；稳定后SDA仍低则置SDA错误。窗口期满进入RELEASE_GUARD。
6. 收尾先释放SDA、保持SCL原资格至少1ms；再撤销SCL资格，稳定1ms后记录未回高的线。finished置1、进入FINISH；全部资格为0，结果保持。
7. 同一posedge依据旧阶段/计数和同步输入计算下一值，非阻塞提交；阶段转移统一清计数。FINISH吸收；任何意外非法状态都撤销SDA、进入有限收尾并置两错误，不能形成循环。

阶段编码用enum且至少3位，可包含IDLE/SCL_LOW/BOTH_LOW/SDA_RELEASE/RELEASE_GUARD/RELEASE_CHECK/FINISH；不截断状态。SCL/SDA原始拉低资格分别保存为寄存器，只在明确阶段边沿更新，再由复位门控输出；禁止组合译码多位状态直接驱动OE，以免阶段切换产生总线毛刺。进入BOTH_LOW只更新SDA资格，进入SDA_RELEASE只撤销SDA资格，SCL资格持续保持；不串联原I2C主控。收尾保持原SCL资格，初始不拉低。
