## 重建过程中的唯一工程设置调整

首次 map 综合成功，之后自动插入调试核失败：`No such file: work_compile/debug_top.v`。当前官方目录的 XML 启用 `debugger/auto_instantiation=on`，同时：

1. 顶层第 1033 行已经实例化 `debug_edb_top debug_edb_top_inst`；
2. XML 已把根目录 `debug_top.v` 列入源码；该文件的模块名为 `debug_edb_top`；
3. Efinity 自动插入流程另外寻找工作目录中的 `debug_top.v`，并以 `edb_top` 为根模块；
4. 已成功的 map 报告包含原显式调试核、LA 和 VIO 的逻辑。

因此只把工作副本 XML 的自动插入开关设为 `off`，保留显式实例化的官方调试核。原始资料没有更改。它是构建配置修正；不是删除 debug_top，也没有改变增益默认值。依据和前后哈希见 `build-configuration-adjustment.json`。保留首次失败日志，复用已成功的 map，继续 interface → pnr → pgm。

工具：现有 Efinity 2026.1.132，Ti60F225 / I3；通过已有英文工具入口和临时 X: 工程盘符调用。临时盘符在命令结束后释放。软件流程不下载硬件。

## 是否比较过 v6/v7 和自研版

是。2026-10-15 已保存研究报告：`../video_research_20261015/摄像头出图与偏色问题研究_20261015.md`，以及 `evidence/source_comparison.json`。此前检查了 v6/v7 的活动源码、031/refine 的时钟复位、帧缓存、像素排列、曝光和增益。没有在当时完成官方源码重建并上板，所以当时不能证明官方预编译 bit 与现有源码完整对应。

本轮进一步比较官方 v7 与最近的 `track4_ddr_cal_diag_001_20261015`：

| 项目 | 本轮源码证据 | 能说明什么 |
|---|---|---|
| PLL、器件/IO bank、LVDS、MIPI DPHY 配置 | XML 各对应子树完全一致 | 这些外围配置已恢复成 v7；不等于整机通路已一致 |
| DDR 顶层实例连接 | 两个实例文本一致 | 已消除先前核心时钟接法差异 |
| DDR 控制器目录 | 16 个文件中 15 个相同；参数头仅 tFAW 为官方 35000、自研 40000 ps | 有一个参数差异，尚未证明它导致不校准 |
| CSI 包类型 | 官方 PACK_TYPE=15；自研 PACK_TYPE=1 | 自研曾裁剪到 RAW10 解包；本轮恢复完整官方配置，不单独归罪于裁剪 |
| 曝光 ROM | 官方 01/BB/F0；自研 00/BA/D0 | 参数不同，不能解释 HDMI 无信号；本轮保持官方值 |
| 帧缓存与发布 | 官方 frame_buffer_V4 + cvo_axi；自研 board_frame_system 等 | 主要结构差异，须用已工作的基线逐段接入验证 |

机器可读比较：`comparison-current.json`、`periphery-diff.json`；顶层、CSI、ROM 的 diff 分别保存。引脚中的按键/LED 分配、未用 DDR 地址高位及 JTAG 配置差异均保留在完整差异文件，不声称整个外围 XML 相同。

自研彩条观察的含义仍是：DDR-CAL-DIAG 版 D0 闪、D1–D5 亮、D6–D7 灭，原始状态为 `0x1F`。D0 在那个诊断版只是核心时钟心跳，不能据此判定校准完成；受保护厂商 IP 中 `0x1F` 的状态名仍未确认。不要将它与官方 v7 的 D0 含义混用。

## 本轮上板验收

最终产物已完成上述检查。使用已配置的板载 USB JTAG 目标，人工临时下载本轮登记的 `.bit`，不要选择 Flash 模式。摄像头继续使用已换好的模组接 J4，HDMI 使用之前官方 v7 能出图的接口。首次观察不按按键，以免同时改变复位或调试状态。

记录四件事即可：

1. Programmer 是否明确成功；实际下载文件路径。
2. 屏幕是否显示真实场景，还是黑屏、彩条、花屏或无信号。
3. 遮挡镜头后画面是否变暗，移开后是否恢复；持续约 1 分钟有无失锁或停帧。
4. 是否仍偏紫/偏绿。相机画面出现不等于颜色已经准确，也不等于全部自研功能通过。

如果本轮重建版能稳定取景，就以它作为后续功能接入的基础；若不能，先与资料包原始 bit 在相同接线条件下对照。颜色/Bayer 和算法接入分别处理，避免一轮同时改变多个因素。
