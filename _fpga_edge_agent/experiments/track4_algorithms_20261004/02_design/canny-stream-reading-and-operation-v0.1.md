# R2流段的中文阅读与操作草图 v0.1

2026-10-04；配套[R2 v0.1](../../../planning/design-TRACK4-ALGORITHM-R2-001.md)，LOCAL_DESIGN / NOT_READY / NOT_APPROVED / NOT_RUN。先读[整包B/C/D](../../../planning/design-TRACK4-ALGORITHM-BATCH-001.md)，再进入本页和R2 E/F/G/H；这是文档草图，不是可执行模型或TB。

## 1. 先看整张图

外部父任务交CJ给C0；C0锁住三ID/尺寸/阈值/median/retain_grad。外部RGB进入内部FE，FE输出预处理灰度Msrc；之后是Gaussian→新的Sobel→整数方向→两支分叉。

一支进入NMS/双阈值，输出NONE/WEAK/STRONG分类；另一支按配置输出grad32。两支的真实交付事实和FE终态回到C0。这里没有完整滞后闭包；分类必须交给后续R4后，才能得到最终Canny边缘。原RGB也必须在最终edge阶段重新取得同坐标原值，不能把Msrc当彩色源。

| 观察对象 | 中文含义 | 谁拥有/何时变化 |
|---|---|---|
| job_snapshot | 本任务完整配置和身份 | C0在CJ实际接纳时锁定，最终终态消费前不借给下一job |
| REAL/pending | 正在接真实灰度及等待RAM旧读回的事件 | Gaussian只对实际输入推进，旧pending消费一次 |
| V1/V2/H1/H2/H3 | 纵算术、纵和、水平项、水平和、最终舍入 | 本模块advance时旧级计算新级，不能同沿串穿 |
| held/两pending | fork的同一组数据及两支接收责任 | 每支只实际接一次；全部旧组释放才替换 |
| N1/N2 | 已选邻居/中心与最终分类 | 后级容量允许才推进，停顿保持整组 |
| input/EOF/empty/status | 接纳、交付、清空和终态四种事实 | 各自按真实事件登记，不能用其中一个代替其余 |

## 2. 先启动，再接像素

CJ接纳沿只锁配置。下一ARM沿才共同start；FE FJ也由C0唯一提出，kind=Y_ONLY、threshold=0、median按快照。原RGB允许须等stream_started和FE已接纳成为旧已锁事实。Msrc是内部接口，不存在第二个外部FE协调器同时消费FS。

尺寸先检查静态W/H相容及至少6×5。原FE可处理4×3，但这个job不能因此启动Canny流段。三ID、中心坐标、标志随事务保持；输出标志从输出中心重建。

## 3. Gaussian：存原灰度，最后才舍入

先保存真实行0/1。读到行2时形成中心0的五行样本0/0/0/1/2；读到行3形成中心1的0/0/1/2/3。后续使用连续五行。读取旧bank值后再做唯一延迟覆写；气泡不等于输入零，也不让旧pending再写一次。

纵和12bit，横向完整和16bit，只有H3加128再右移8。顶部/左右复制合法边界；末真实行以后两个底部重放加TAIL补完末行/末pair。TAIL是控制事件，没有真实像素，不增加输入数量。

例子：在内圈给纵轴权重4、横轴权重1的位置单值30，完整sum120，最终0。若每轴都提前舍入会得到不同结果。这是人工期望推导，不是已经运行的测试。

## 4. 新梯度、方向、NMS各自交接

新Sobel读取Gaussian完整图，独立复制自己的3×3边界。原FE先算过的梯度不能替代它。六级梯度同组输出后，方向D1先检查abs和值域，再用20bit整数424/1024比较；零灰度不意味着零梯度方向。

NMS历史保留原幅值，包括外框。只在当前中心为外框时分类NONE；内圈邻居比较仍可能需要那个较大的外框值。每个方向的负邻/正邻和相等策略固定，不随梯度反号改变。

TL/TH整job不变。TH≥1530没有STRONG，但可有WEAK；弱边是否留下必须由后续完整闭包决定，本页不能直接全置NONE。

## 5. 停顿时看“事件”，别只数时钟拍

若末级有数据且下游不ready，该模块数据、坐标、配置、pending和RAM读回全部保持，RAM新使能关闭。其他模块仍依据自己的末级容量推进或排尾。

fork某支已收后只清这一支pending；另一支停顿时旧payload保持。旧两支释放并接新组同沿，新pending初始化覆盖旧清位，新组不透传。class统计只有实际交付才增加，valid保持十拍不能累加十次。

局部首/末边沿表只适用于连续输入且持续ready等限定条件；它不是整个系统固定延迟，也不是STA通过。参考波形要分别定位真实fire、中心、EOF实际交付和empty。

## 6. 终态和RGB仍需补设计

FE先OK时，C0及时消费保存原FS，继续等分类/梯度尾部。FE返回IDLE不能释放R2快照。取消与FE OK同沿保存原FE OK，同时R2作废；已交付前缀不删除。新status的编码/优先级/取消全事件仍未冻结。

不能在原RGB与实时FE分叉处只放一组RGB保持器：它会反压源，使FE无法填够窗口，双方等待。独立同序可暂停的RGB/最终edge重放才可做有限held配对；重放来源、容量和失败必须由后续设计证明。

生产工程还要另冻结observer记录/仲裁/CRC与pin/SDC。R1的160bit记录容不下185bit grad。当前Gaussian8+新Sobel4+NMS8=20 RAM10，加FE8=28只是结构预算，不是综合测量或完整R2资源通过。
